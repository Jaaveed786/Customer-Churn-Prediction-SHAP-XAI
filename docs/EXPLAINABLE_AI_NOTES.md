## 💡 What is Explainable AI (XAI)?

Explainable AI refers to methods and techniques that allow human users to understand and trust the results and output generated by machine learning algorithms.

In high-stakes industries (Finance, Healthcare, Telecom Retention), a model that outputs `73% Churn Risk` without explaining **why** is useless. Business teams need actionable drivers to design intervention offers.

## 🎲 Game Theory Foundations: Shapley Values

SHAP is built on **Shapley Values**, developed by Nobel laureate Lloyd Shapley in 1953 for cooperative game theory.

### The Game Analogy:
- **Players** = Features (e.g., `tenure`, `MonthlyCharges`, `Contract`)
- **Game** = Predicting customer churn probability
- **Payout** = Difference between prediction and average base prediction ($\mathbb{E}[f(x)]$)

### Mathematical Formula:
The Shapley value $\phi_i$ for feature $i$ is calculated as the weighted average marginal contribution across all possible feature subsets $S$:

$$\phi_i(x) = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!(|F| - |S| - 1)!}{|F|!} \left[ f_x(S \cup \{i\}) - f_x(S) \right]$$

Where:
- $F$ is the set of all features.
- $S$ is a subset of features excluding feature $i$.
- $f_x(S)$ is the model prediction using only feature subset $S$.

---

## 📜 The 4 Fundamental Axioms of SHAP

Shapley values are the **only** additive feature attribution method that satisfies all four axioms:

1. **Efficiency (Additivity):**
   The sum of SHAP values for all features equals the difference between the model output $f(x)$ and the baseline expected value $\mathbb{E}[f(x)]$:
   $$f(x) = \mathbb{E}[f(x)] + \sum_{i=1}^{M} \phi_i(x)$$

2. **Symmetry:**
   If two features $i$ and $j$ contribute equally to all feature coalitions, their SHAP values are identical: $\phi_i = \phi_j$.

3. **Dummy (Null Player):**
   If a feature $i$ provides zero marginal contribution to all coalitions, its SHAP value is zero: $\phi_i = 0$.

4. **Additivity:**
   For combined models $f + g$, the combined SHAP value is $\phi_i(f + g) = \phi_i(f) + \phi_i(g)$.

## 📈 Visualizing SHAP Explanations

### 1. Local Waterfall Plot (Single Prediction)
Shows how a specific customer's prediction starts at the baseline average ($E[f(X)] \approx 26.5\%$) and moves step-by-step to the final probability:
- **Red Arrows (+):** Push churn probability higher (e.g. Month-to-month contract adds +18%).
- **Green Arrows (-):** Pull churn probability lower (e.g. Auto-payment subtracts -5%).

### 2. Global SHAP Summary Dot Plot (Dataset Level)
Combines feature importance with feature effects:
- **Y-Axis:** Features sorted by global importance (top to bottom).
- **X-Axis:** SHAP value (impact on model output).
- **Color Scale:** High feature value (Red) vs. Low feature value (Blue).
- **Example Pattern:** If red dots for `MonthlyCharges` lie on the positive X-axis (right), it means high monthly bills consistently increase churn risk across all customers.

### 3. Global Feature Importance Bar Chart
Computes the mean absolute SHAP value across all samples:

$$I_j = \frac{1}{N} \sum_{i=1}^{N} |\phi_j^{(i)}|$$

Represents the overall magnitude of impact for feature $j$.
