## 🤖 Overview of Antigravity AI

**Antigravity** is Google DeepMind's flagship agentic AI coding environment designed for Pair Programming, Autonomous System Architecture, and Enterprise Software Engineering.

Unlike simple autocomplete engines, Antigravity acts as an autonomous senior technical pair-programmer capable of:
1. **Systemic Codebase Research & Planning:** Analyzing project dependencies, schema contracts, and domain requirements before writing code.
2. **Deterministic Preprocessing & Pipeline Scoping:** Ensuring complete zero-leakage scikit-learn pipeline compliance.
3. **Subagent Parallelization:** Launching dedicated background subagents to scaffold modules, test suites, and stylesheets concurrently.
4. **Self-Healing Verification & Error Diagnosis:** Running unit tests (`pytest`), reading stack traces, and fixing edge-case bugs (such as pandas 2.1+ `applymap` deprecations and Windows `cp1252` encoding constraints) automatically.

## 🎨 Design System Choices & UI Philosophy

Antigravity enforced the following design principles to ensure a **WOW factor** UI:

1. **Controlled Bounded Layouts:** Image elements use explicit column grids (`st.columns([0.15, 0.7, 0.15])`) to prevent full-screen image stretching or zoom clipping.
2. **Glassmorphism Dark Theme (`#0f1117`):** Custom CSS design system with subtle backdrop filters, glowing accent borders (`#8b5cf6`), and high-contrast typography (`Plus Jakarta Sans`).
3. **Custom HTML Metric Components:** Replaced default pandas dataframes with custom HTML comparison tables featuring glowing status badges (`84.6% ROC-AUC`, `90.4% Recall`).
4. **Plain-English Explainer Guide Cards:** Placed informative explanation boxes above every plot so non-technical stakeholders can understand complex SHAP and ROC outputs.
